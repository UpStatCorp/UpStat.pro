## 1. Общая схема

```mermaid
flowchart TB
    subgraph INPUT["📞 ВХОД"]
        A1[Запись звонка / текст]
    end

    subgraph ANALYSIS["📋 АНАЛИЗ"]
        B1[Транскрибация → JSON-диалог]
        B2[Проверка по чек-листам<br/>5 этапов продаж]
        B3[Итоговый отчёт<br/>ошибки + рекомендации]
    end

    subgraph PASSPORT["📊 ПАСПОРТ ПРОДАВЦА"]
        C1[GPT оценивает менеджера<br/>по 5 этапам]
        C2["Баллы 0–100%<br/>contact · needs · presentation<br/>objections · closing"]
        C3[Сохранение в БД<br/>профиль + история]
    end

    subgraph TRAINING["🎯 ТРЕНИРОВКА"]
        D1[Выбор самого слабого этапа<br/>минимальный балл]
        D2[1 тренировка по критичной ошибке]
        D3[Голосовая отработка с ИИ]
        D4{Валидатор<br/>≥ 70 баллов?}
    end

    subgraph LOOP["🔄 КОНТРОЛЬ"]
        E1[Следующий звонок]
        E2[Сравнение баллов<br/>до / после тренировки]
        E3[Тренировка сработала?]
    end

    A1 --> B1 --> B2 --> B3
    B3 --> C1 --> C2 --> C3
    C2 --> D1 --> D2 --> D3 --> D4
    D4 -->|Да| E1
    D4 -->|Нет| D2
    E1 --> B1
    E1 --> E2 --> E3
    E3 -->|Новый слабый этап| D1
```

## 2. Детальная схема по этапам

```mermaid
flowchart LR
    subgraph S1["1. ЗВОНОК"]
        direction TB
        Z1[Аудио / текст]
        Z2[Диалог с ролями<br/>менеджер ↔ клиент]
    end

    subgraph S2["2. АНАЛИЗ"]
        direction TB
        A1[Чек-лист: Контакт]
        A2[Чек-лист: Потребности]
        A3[Чек-лист: Презентация]
        A4[Чек-лист: Возражения]
        A5[Чек-лист: Закрытие]
        A6[Отчёт analysis.txt]
    end

    subgraph S3["3. ПАСПОРТ"]
        direction TB
        P1[GPT: 5 баллов]
        P2["Пример:<br/>closing = 1% ← слабее всего"]
    end

    subgraph S4["4. НАЗНАЧЕНИЕ"]
        direction TB
        T1[Этап: closing]
        T2[Карточка тренировки<br/>проблема + рекомендация]
    end

    subgraph S5["5. ОТРАБОТКА"]
        direction TB
        V1[ИИ-тренер<br/>4 этапа сценария]
        V2[Валидатор 70+]
    end

    Z1 --> Z2 --> A1 & A2 & A3 & A4 & A5
    A1 & A2 & A3 & A4 & A5 --> A6
    A6 --> P1 --> P2 --> T1 --> T2 --> V1 --> V2
```

## 3. Пять этапов продаж

```mermaid
flowchart LR
    subgraph STAGES["Воронка продаж"]
        direction LR
        S1["1️⃣ Контакт<br/>contact"]
        S2["2️⃣ Потребности<br/>needs"]
        S3["3️⃣ Презентация<br/>presentation"]
        S4["4️⃣ Возражения<br/>objections"]
        S5["5️⃣ Закрытие<br/>closing"]
    end

    S1 --> S2 --> S3 --> S4 --> S5
```

| Диапазон | Интерпретация |
|----------|---------------|
| 0–4% | Этап пропущен или провален |
| 5–10% | Критические ошибки |
| 11–25% | Много упущений |
| 26–50% | Средний уровень |
| 51–70% | Хорошо |
| 71–100% | Отлично |

## 4. Замкнутый цикл обучения

```mermaid
sequenceDiagram
    participant M as Менеджер
    participant S as UpStat
    participant AI as ИИ

    M->>S: Загружает звонок
    S->>AI: Анализ по чек-листам
    AI-->>S: Отчёт с ошибками
    S->>AI: Оценка по 5 этапам
    AI-->>S: Паспорт (баллы)
    Note over S: Самый слабый этап
    S->>AI: Сформировать 1 тренировку
    AI-->>S: Карточка тренировки
    S->>M: Назначена тренировка
    M->>AI: Голосовая отработка
    AI->>S: Валидатор ≥70?
    alt Прошёл
        S->>M: Тренировка засчитана
    else Не прошёл
        S->>M: Повторить тренировку
    end
    M->>S: Следующий звонок
    S->>S: Сравнение до/после
```

## 5. Что видит руководитель

```mermaid
flowchart TB
    CALL[📞 Звонок менеджера]
    CALL --> REPORT[📄 Отчёт]
    CALL --> PASSPORT[📊 Паспорт — 5 цифр]
    PASSPORT --> WORST[🔴 Самый слабый этап]
    WORST --> ONE[🎯 1 тренировка]
    ONE --> VOICE[🎙 Голосовая отработка]
    VOICE --> CHECK{Зачёт ≥70?}
    CHECK -->|Да| DONE[✅ Засчитано]
    CHECK -->|Нет| RETRY[↩ Повтор]
    DONE --> NEXT[📞 Следующий звонок]
    NEXT --> DELTA[📈 Динамика]
```
