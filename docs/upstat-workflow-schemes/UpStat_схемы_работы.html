1. Общая схема

flowchart TB
    subgraph INPUT["📞 ВХОД"]
        A1[Запись звонка / текст]
    end

    subgraph ANALYSIS["📋 АНАЛИЗ"]
        B1[Транскрибация → JSON-диалог]
        B2[Проверка по чек-листам
5 этапов продаж]
        B3[Итоговый отчёт
ошибки + рекомендации]
    end

    subgraph PASSPORT["📊 ПАСПОРТ ПРОДАВЦА"]
        C1[GPT оценивает менеджера
по 5 этапам]
        C2["Баллы 0–100%
contact · needs · presentation
objections · closing"]
        C3[Сохранение в БД
профиль + история]
    end

    subgraph TRAINING["🎯 ТРЕНИРОВКА"]
        D1[Выбор самого слабого этапа
минимальный балл]
        D2[1 тренировка по критичной ошибке]
        D3[Голосовая отработка с ИИ]
        D4{Валидатор
≥ 70 баллов?}
    end

    subgraph LOOP["🔄 КОНТРОЛЬ"]
        E1[Следующий звонок]
        E2[Сравнение баллов
до / после тренировки]
        E3[Тренировка сработала?]
    end

    A1 --> B1 --> B2 --> B3
    B3 --> C1 --> C2 --> C3
    C2 --> D1 --> D2 --> D3 --> D4
    D4 -->|Да| E1
    D4 -->|Нет| D2
    E1 --> B1
    E1 --> E2 --> E3
    E3 -->|Новый слабый этап| D1

4. Замкнутый цикл обучения

sequenceDiagram
    participant M as Менеджер
    participant S as UpStat
    participant AI as ИИ

    M->>S: Загружает звонок
    S->>AI: Анализ по чек-листам
    AI-->>S: Отчёт с ошибками
    S->>AI: Оценка по 5 этапам
    AI-->>S: Паспорт (баллы)
    Note over S: Самый слабый этап
например closing = 1%
    S->>AI: Сформировать 1 тренировку
    AI-->>S: Карточка тренировки
    S->>M: Назначена тренировка
    M->>AI: Голосовая отработка
    AI->>S: Валидатор ≥70?
    alt Прошёл
        S->>M: Тренировка засчитана
    else Не прошёл
        S->>M: Повторить тренировку
    end
    M->>S: Следующий звонок
    S->>S: Сравнение: было 1% → стало 3.2%?
    Note over S: Фиксация эффекта
тренировки

5. Что видит руководитель

flowchart TB
    CALL[📞 Звонок менеджера]

    CALL --> REPORT[📄 Отчёт
что сделал хорошо / где ошибся]

    CALL --> PASSPORT[📊 Паспорт
5 цифр по этапам продаж]

    PASSPORT --> WORST[🔴 Самый слабый этап]

    WORST --> ONE[🎯 1 тренировка
не 5–6 сразу]

    ONE --> VOICE[🎙 Голосовая отработка]

    VOICE --> CHECK{Зачёт?}

    CHECK -->|70+| DONE[✅ Навык зафиксирован]
    CHECK -->|<70| RETRY[↩ Повтор]

    DONE --> NEXT[📞 Следующий звонок]
    NEXT --> DELTA[📈 Динамика:
помогла ли тренировка?]
