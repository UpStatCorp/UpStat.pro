# Схемы UpStat — как скачать

## Файлы в этой папке

| Файл | Формат | Для чего |
|------|--------|----------|
| **UpStat_схемы_работы.html** | HTML | **Лучший вариант для шефа** — открыть в браузере, все 5 схем на одной странице |
| **UpStat_схемы_работы.md** | Markdown | Исходники с Mermaid (для редактирования) |

## Как получить PDF

1. Откройте `UpStat_схемы_работы.html` двойным кликом (Safari / Chrome).
2. Нажмите **Cmd+P** (Mac) или **Ctrl+P** (Windows).
3. Выберите **«Сохранить как PDF»**.
4. Готово — можно отправить шефу.
