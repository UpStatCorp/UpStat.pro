### 3. [High] CORS в ai_agent_service

**Было:**
```python
allow_origins=["*"]
allow_credentials=True
```

**Стало:**
```python
_cors_env = os.getenv("CORS_ALLOW_ORIGINS", "").strip()
_allow_origins = [o.strip() for o in _cors_env.split(",") if o.strip()] if _cors_env else []
allow_origins=_allow_origins
allow_credentials=bool(_allow_origins)
```

Сервис по умолчанию **без CORS** (внутренний). Для браузерного доступа — явно задать `CORS_ALLOW_ORIGINS`.

### 4. [High] XSS в панели уведомлений

**Проблема:** `${n.title}`, `${n.link}` вставлялись в `innerHTML` без экранирования. CSP содержит `unsafe-inline`.

**Сделано в `_layout_dashboard.html`:**
```javascript
function escapeHtml(value) { ... }
function safeUrl(value) {
  // только относительные / и http(s)://
}
// renderNotifications использует escapeHtml/safeUrl
```

`notifications.js` уже экранировал — подтверждено при аудите.

**Не сделано (P1 backlog):** убрать `unsafe-inline` из CSP, вынести inline-скрипты в файлы, nonce.

### 6. [Medium] CSRF через Origin/Referer

**Новый middleware:** `_CSRFOriginMiddleware` в `app/main.py`

- Проверяет POST/PUT/PATCH/DELETE.
- `Origin` или `Referer` должны совпадать с `Host`.
- Исключение: `/crm/webhook/` (внешние вебхуки).
- При несовпадении → **403** `CSRF: origin mismatch`.

> Проверено: кросс-доменный POST → 403.

### 7. [Medium] CRM webhook secret

**Файл:** `app/routers/crm_integration.py`

```python
import secrets as _secrets
if not integration.webhook_secret or not _secrets.compare_digest(
    str(integration.webhook_secret), str(webhook_secret)
):
    raise HTTPException(403, "Invalid webhook secret")
```

**Маскировка в логах** (`app/main.py`, `_safe_log_url`):
- Путь `/crm/webhook/{id}/{secret}` → secret заменяется на `***`
- Query string → `<redacted>`

> Секрет по-прежнему в URL (legacy). Backlog: перенести в заголовок/HMAC.

### 8. [Medium] Account lockout на логин

**Файл:** `app/routers/auth.py`

- После **10** неудачных попыток → блок на **15 минут** (429).
- Ключ: `login_fail:{email}` через `get_cache_service(REDIS_URL)`.
- При успешном входе — счётчик сбрасывается.
- С Redis — общий между воркерами; без Redis — in-memory.
